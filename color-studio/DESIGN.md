# 색의 발견 — 승인 디자인과 구현 구성

Apple 홈페이지의 정돈된 타이포그래피와 여백을 참고해 흰색·옅은 회색 바탕, 짙은 글자, 중앙의 큰 제목, 펼쳐진 컬러 팔레트, 파란 버튼으로 재구성했다. Apple 기기에서는 시스템 서체를 우선 사용하고 다른 기기는 자체 호스팅한 Pretendard Variable로 한글을 표시한다. 성별을 특정하는 뷰티 광고 대신 관찰·학습·일상 활용을 중심에 둔다. 사진에서 색을 자동 진단하지 않는다.

## 세 역할의 화면

- **강사 컨트롤:** 수업 초대 QR·링크·코드, 9단계와 단계 내 슬라이드, 동기화·활동·공유 토글, 타이머, 조별 진행률과 재비교 요청, 강사 전용 노트, 시간·계절 이름·실물 키트 편집, 발표 공개·수업 종료·삭제.
- **발표:** 한 화면 한 메시지와 큰 색 비교, 지금 할 일·남은 시간·참여 코드. 23장으로 180분 흐름을 진행한다. 개인 워크북·강사 메모·학생 별명·댓글은 발표 응답에서 제외한다. 동의한 스타일 게시물만 별도로 표시한다.
- **참여 워크북:** 좋아하는 세 색과 완료 후 캐릭터 공개, 기초 학습, 색상 선택·명도 배열·채도·색조·웜쿨, 비교 조건과 역할, 색상별 나/조원 관찰, 원하는 이미지와 색 조합 연결, 조별 스타일 보드와 피드백, 결과 정리·다운로드·인쇄용 화면.

9단계 기본 시간은 10 / 15 / 20 / 15 / 5 / 70 / 10 / 30 / 5분 = 180분이다. 5~6개 조에 키트 1세트씩, 역할을 순환한다. 6명 조는 1인 약 10분과 재비교 10분을 기준으로 진행한다.

## 결정 사항

- 키트 색·장수·계절 이름을 확정하지 않는다. 기본 팔레트는 예시이며 강사가 색상 묶음과 비교색을 추가·삭제·편집한다.
- 남/여 캐릭터를 먼저 선택하고 좋아하는 색 3개를 고른다. 완료 전에는 캐릭터가 보이지 않는다. 색을 바꾸면 다시 완료해야 공개된다. SVG는 참고 분위기를 바탕으로 새로 만든 원화이며 모자·상의·하의는 무늬 없이 색을 적용한다.
- 조원 의견은 복수 선택과 자유 기록을 허용한다. 내 의견과 달라도 각각 남긴다. 비슷함·모름·재비교를 제공한다.
- 참여자가 입력 중일 때 단계 변경은 안내만 띄우고 내용을 보존한다. 이전 기록은 언제든 확인한다.
- 결과는 선택 횟수로 계절 유형을 확정하지 않는다. 색상별 기록, 반복 관찰, 이견, 재비교 대상, 스타일 선택과 받은 의견을 모은다.
- 이미지 스케일은 자체 제작 개념 도표다. 단어·조합 선택·이유 기록으로 원하는 이미지와 실습을 연결한다.
- 다른 조 접근은 서버에서 검사하며 강사 인증은 방 코드와 분리한다. 발표 동의는 작성자만 변경한다.

실행·보관·권한·복구 방식은 README.md, 실제 검사 결과와 미검증 범위는 VALIDATION.md에 정리했다. 외부 배포와 현장 검증은 아직 수행하지 않았다.

## 디자인 변경 검증

새 디자인에서 기존 다중 브라우저 검사 2개와 API 검사 3개를 통과했다. 360px 워크북·강사 설정의 가로 넘침, 23개 슬라이드의 1280×720 표시, 실제 한글 웹폰트 로딩을 확인했다. 새 CSS와 서체를 오프라인에서도 받도록 서비스 워커 캐시 버전을 변경했다. Apple 기기의 실제 서체 렌더링은 해당 기기에서 추가 확인이 필요하며, 공개 Render 배포 여부는 별개다.
