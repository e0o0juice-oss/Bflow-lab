# Personal PDF report

학생 브라우저에서 pdf-lib와 fontkit으로 실제 A4 PDF를 만든다. Chromium 서버나 외부 PDF 변환 서비스 없이 작동하며 개인 워크북 내용을 PDF 변환 API로 전송하지 않는다.

## 포함 내용

- 본인 별명·조, 내 캐릭터(색 선택 완료 시), 좋아하는 세 색.
- 비교 조건, 색상별 나/조원 관찰·메모, 의견 차이와 재비교 항목.
- 본인이 선택·배열한 개념 학습 답과 이유, 강사가 공개한 답과 해설만 포함.
- 원하는 이미지·색 조합·연결 방법.
- **본인이 직접 올린** 스타일 이미지·이유·받은 댓글. 댓글 작성자 별명과 타인의 게시물은 제외.
- 좋아하는 색의 이야기·오늘의 발견·다음 시도 기록과 활용 가이드.

한글을 검색·복사할 수 있는 텍스트로 넣고, 긴 글은 자동으로 다음 페이지에 이어 쓴다. 한글 복합 글리프의 서브셋 오류를 피하기 위해 정적 TrueType 전체 글꼴을 PDF 안에 포함한다. 이미지 크기와 기록 길이에 따라 페이지 수·파일 크기가 달라진다. 예시는 약 2.6MB다. 폰트가 지원하지 않는 일부 이모지/기호는 □로 표시하고 저장 상태와 PDF에 원문 텍스트 백업 안내를 남긴다.

마지막 클릭 시점의 개인 기록을 복사해 PDF를 만든다. 수업 참여자는 서버에서 공유 기록·피드백을 새로 확인하고, 본인 이미지를 모두 읽을 수 있어야 저장한다. 게시판이나 이미지 확인에 실패하면 불완전한 PDF를 조용히 내려주지 않고 중단·재시도 안내를 표시한다. 개인 연습은 공유 항목 없이 저장할 수 있다. 텍스트 백업은 별도로 유지한다.

## 개발·빌드

```bash
cd color-studio/report
npm ci --ignore-scripts
npm run build
npm test
```

`vendor/report.min.js`, 라이선스 고지와 `fonts/Report*.ttf.br`를 준비한다. 앱 실행에는 이 패키지의 node_modules가 필요 없고, 필요한 산출물을 Git에 포함하므로 Render의 기존 실행 명령을 유지할 수 있다.

원본 UI 글꼴은 Pretendard 1.3.9이다. PDF 정적 글꼴 재생성이 필요하면 fontTools와 Brotli가 준비된 개발 환경에서 `python prepare-fonts.py`를 실행한 뒤 빌드한다. 수정 폰트는 SIL OFL의 Reserved Font Name 조건에 맞춰 내부 이름을 **Color Studio Report**로 바꾸었다. 원본 저작권과 라이선스 정보는 유지한다. OFL은 `../fonts/OFL.txt`에 있다. 파생 폰트는 브라우저가 지원하면 Brotli로 전달하고 첫 사용 후 서비스 워커에 캐시한다.

## 검증

- `npm test`: 실제 PDF 로딩, A4 크기·한글 추출, 본인/타인 자료 구분, 댓글 작성자 이름 제외, 긴 기록의 끝 보존·페이지 경계, 이미지 포함·누락 시 중단.
- 저장소의 `color-studio`에서 `node --test report.browser.test.cjs`: 강사/학생/조원 분리, 실제 이미지 업로드와 피드백, 마지막 메모의 저장·새로고침 복원, 실제 PDF 다운로드와 내용 검사, 이미지 네트워크 실패 시 추가 다운로드 없음.
- 실제 PDF를 pdftoppm으로 렌더링하고 표지·내용·이미지 페이지를 시각 검토했다. PDF 텍스트 추출만으로 폰트 표시가 정상이라고 판단하지 않는다.

실제 iOS/Android 파일 앱의 저장 흐름·교실 네트워크·공개 Render 주소에서의 다운로드는 추가 확인이 필요하다. 인쇄 결과는 RGB 화면 색과 다를 수 있으므로 실물 진단 기준으로 쓰지 않는다.
