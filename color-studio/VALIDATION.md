# 검증 실행 근거 — 색의 발견

아래는 현재 클라우드의 로컬 Node 서버와 Chromium에서 직접 실행한 결과다. 외부 공개 서비스나 현장 수업이 검증됐다는 의미는 아니다.

## 통과한 자동 검사

### API · 저장 · 권한: 3개 테스트 통과

명령: `npm test --prefix color-studio`

- 수업 생성, 기본 시간 합계 180분, 강사 노트의 강사 전용 제공.
- Render의 `RENDER_EXTERNAL_URL` 자동 사용, HTTPS 출처 허용·다른 출처 거부, Secure 쿠키 발급.
- 학생의 강사 제어·설정·발표 API 접근 거부, 다른 출처의 변경 요청 거부.
- 개인 워크북 본인 전용 조회, 강사 진행률 응답에서 개인 메모 제외.
- 저장 버전 충돌 거부와 동일 요청 ID 재시도 중복 방지.
- 공유 활동을 열기 전 업로드 거부, 허용하지 않는 이미지 형식 거부.
- 같은 조 조회·의견, 다른 조 목록/직접 이미지 URL/댓글 접근 거부.
- 작성자 외 발표 동의 변경 거부. 미동의 게시물 발표 거부.
- 동의 후 공개, 발표 응답에서 별명·댓글·개인 기록·강사 노트 제외.
- 동의 철회 시 현재 발표 항목 제거.
- 강사 시간·계절 이름·비교색 개수 편집, 타이머 시작과 정지.
- 실제 서버 프로세스를 닫고 같은 데이터 디렉터리로 다시 열어 워크북·설정·댓글·단계 복원.
- 재참여로 조 변경 불가, 종료 후 새 기록 거부, 본인 동의 철회 가능, 수업 삭제 시 이미지 제거.
- **30개 독립 참여 세션과 30개 SSE 연결**의 동시 입장·단계 수신·독립 기록 저장, 6개 조에 각 5명 집계.

이 부하 검사는 같은 로컬 호스트의 HTTP 연결 시뮬레이션이다. 실제 30대의 휴대폰·학교 Wi-Fi·셀룰러망이나 3시간 내구성 검사는 아니다.

### 실제 Chromium 화면: 2개 테스트 통과

명령: `COLOR_TEST_ARTIFACTS=/workspace/scratch/color-studio-review npm run test:browser --prefix color-studio`

- 분리된 강사 브라우저 컨텍스트 1개, 학생 컨텍스트 3개(같은 조 2명, 다른 조 1명), 강사 브라우저의 발표 탭으로 실동작.
- 좋아하는 색 3개 선택 중 캐릭터 미노출 → 완료 후 공개.
- 기록 중 강사 단계 변경 시 입력 유지와 이동 안내.
- 단계 연결 끄기와 학생 자유 탐색.
- 기기/서버 저장 후 새로고침 복원.
- 브라우저 오프라인 전환 중 입력, 연결 복귀 후 서버 저장.
- 서비스 워커 설치 후 **완전 오프라인 상태에서 새로고침**, 기존 워크북 복원, 추가 입력, 재연결 후 저장.
- 명도 순서 변경, 개념 학습 이유 기록.
- 타이머 실제 감소와 일시정지 유지.
- 실제 PNG 파일 선택 → 브라우저 JPG 변환 → 업로드 → 같은 조 다른 브라우저 표시.
- 같은 조 의견 작성, 다른 조 게시판에서 미표시.
- 발표 동의·강사 공개·철회 시 발표에서 이미지 제거.
- 받은 의견이 결과에 포함되고 텍스트 파일 다운로드 발생.
- 단계 시간·계절 이름·색상 개수 편집 후 새로고침 유지, 실물 키트 확인 표시.
- **360px 모바일**에서 9개 워크북 활동과 강사 설정 가로 넘침 없음.
- **1280×720 발표 화면에서 23개 슬라이드 전체**의 가로·세로 넘침 없음.
- 브라우저 JavaScript 예외 없음.

현재 테스트 도구: Node.js 24.22.1, Playwright 1.62.1, `/usr/bin/chromium`.

### QR 확인

생성된 QR을 실제 브라우저에서 PNG로 캡처하고 jsQR로 디코딩했다. 결과가 해당 수업 참여 링크와 정확하게 일치했다. 외부 QR 생성 API는 쓰지 않는다. 실제 휴대폰 카메라로 스캔하는 현장 검증은 미실시다.

### 기존 앱 회귀 검사

기존 루트 `npm test`: 2개 통과. 기존 앱의 추적 파일은 변경하지 않았으며 새 앱은 `color-studio/`에 분리했다.

## 아직 검증하지 않은 운영 항목

- 외부 HTTPS 서비스 배포, 실제 도메인과 `PUBLIC_ORIGIN`, Secure 쿠키·TLS·리버스 프록시 SSE 설정.
- 호스팅 플랫폼의 영구 디스크, 스냅샷 복원과 재배포 후 데이터 유지. 로컬 같은 디렉터리의 프로세스 재시작은 검증했다.
- 실제 휴대폰 QR 스캔, iOS Safari·Android Chrome, 30대 동시 현장 접속, 3시간 연속 운영.
- 교실 Wi-Fi와 조명, 프로젝터 색 재현, 실제 구입한 키트의 색·장수·계절 대응.
- 운영체제의 인쇄/PDF 저장 대화상자와 인쇄 결과물. 결과 텍스트 다운로드와 결과 화면은 확인했다.

## 재현과 정리

API·브라우저 테스트는 임시 포트·임시 데이터 디렉터리를 사용하며 종료 시 서버와 테스트 데이터를 정리한다. 화면 캡처는 지정한 별도 경로에 남는다. 캡처의 수업 코드·QR은 일회성 테스트 서버 주소이며 실제 수업 초대에 쓰면 안 된다.

실제 수업 전에는 접근 가능한 HTTPS 주소와 영구 디스크를 준비하고, 실제 기기로 강사/학생/발표·QR·업로드·복귀·결과 저장을 리허설한다. 환경 설정 초안 저장과 Publish, 외부 웹서비스 배포는 서로 다른 작업이다.
